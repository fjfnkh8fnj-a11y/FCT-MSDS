등록된 MSDS가 없습니다.관리자가 PDF를 등록하면 이곳에 표시됩니다.

사용물질 등록

사용물질을 먼저 등록하고 MSDS PDF는 선택하여 첨부할 수 있습니다.

1. 사용처 등록

2. 물질명 입력

3. 비고

4. MSDS PDF 첨부 (선택)

등록 기준

  1. 한 번 등록할 때 공장 하나만 선택합니다.
  2. 같은 공장 안에서는 사용처를 여러 개 지정할 수 있습니다.
  3. 물질명만 먼저 저장하고 PDF는 나중에 첨부할 수 있습니다.
  4. 1공장과 2공장의 사용물질은 각각 관리합니다.

사용방법

MSDS를 찾고 확인하는 방법입니다.

MSDS 열람

  1. 공장을 선택합니다.
  2. 부서와 설비를 차례로 선택합니다.
  3. 물질명을 누르고 PDF 보기 또는 다운로드를 선택합니다.

물질 검색

전체 화면의 검색창에 물질명을 입력하면 해당 물질만 표시됩니다.

관리자 사용방법

  1. 사용물질 등록에서 사용처·물질명·비고를 저장합니다.
  2. PDF가 없으면 나중에 PDF 미등록 현황에서 바로 첨부합니다.
  3. 엑셀 관리에서 전체 자료를 내려받거나 일괄 등록합니다.
