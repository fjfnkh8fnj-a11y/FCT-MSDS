FCT MSDS VER7_rev.7

[VER7 기능 추가·개선]
- 로고의 흰 바탕 제거 및 네이비 헤더에 맞춘 흰색 로고 적용
- 화면의 `처음으로` 버튼 제거
- 회사 로고 클릭 시 검색과 선택을 초기화하고 전체 MSDS 첫 화면으로 이동
- 일반 열람 화면의 `공개 열람` 상태 표시 제거
- 관리자 로그인 상태에서만 `관리자 모드` 표시
- 헤더에 원본 `FCT (주) 화인세라텍` 전체 로고 적용
- 구조 관리의 수정·삭제·순서변경 버튼 클릭 처리 오류 수정
- 잘못 입력한 공장·부서·설비·공정을 정상적으로 삭제 가능
- Supabase FCT-MSDS 공용 데이터베이스·PDF 저장소 연결
- 데모 모드 종료 및 여러 기기 공용자료 운영 전환
- 화면과 엑셀 다운로드에서 등록일 항목 제거
- 엑셀 업로드 필수 열을 공장·부서·설비·공정·물질명·PDF파일명으로 확정
- 엑셀 1개와 PDF 여러 개를 선택해 전체 자료 일괄등록
- 엑셀만으로 공장·부서·설비·공정·물질명·사용 위치 자동 생성
- 등록 전 물질·사용 위치·오류 건수 미리 확인
- 같은 공장·물질명·PDF 파일명은 하나로 묶고 모든 사용처 표시
- 대상 공장 지정 시 기존 PDF를 공장별 독립 사본으로 복사
- 1공장과 2공장의 PDF 원본·자료를 완전히 별도 관리
- 한 공장 안에서 여러 부서·설비·공정 사용처 선택
- PDF 재업로드 없이 물질명과 사용 위치 수정
- 필요할 때만 PDF 파일 교체
- 삭제 시 현재 공장 자료만 삭제하고 다른 공장 자료는 유지
- 엑셀·ZIP 파일명 VER7 기준 적용
- PC 모드와 모바일 모드를 사용자가 직접 변경
- 전체 → 공장 → 부서 → 설비 → 공정 단계형 이동
- 선택한 단계에 포함된 MSDS 전체 표시
- 1공장과 2공장 자료를 서로 분리해서 표시
- 물질명만 검색하는 전용 검색
- 아이폰·안드로이드 PDF 전체 화면 및 화면 맞춤 개선

[기존 기능 유지]
- 관리자 공통 비밀번호 1004
- PDF 등록·열람·다운로드 및 엑셀 관리
- 공장·부서·설비·공정 추가·수정·삭제
