FCT-MSDS VER12_rev.3
수정일: 2026-09-28

1. 성분정보 입력 화면 개선
- 성분별 판정근거 수기 입력칸 삭제
- 성분의 CAS No.와 함량을 법적 기준과 자동 비교
- 규제명, 적용 기준 함량, 현재 함량, 해당·비해당·확인 필요를 표시
- 황산 기준 예시: 인체급성유해성물질 10% 이상, 사고대비물질 10% 이상
- 공정안전보고서처럼 취급·저장량 확인이 필요한 항목은 확인 필요로 표시

2. 엑셀 개선
- 성분판정근거 열을 성분별 적용기준 열로 변경
- 자동 계산된 적용 기준과 판정 결과를 내려받도록 변경

3. PC 현황판 배열 변경
- 일반 현황 카드 4개를 PC에서 한 줄 1×4로 표시
- 모바일은 기존 2열 배열 유지

주의
- 표시 기준은 등록된 MSDS 기재내용을 기준으로 하며, 최신 법령과 실제 취급·저장량은 관리자가 최종 확인해야 합니다.
